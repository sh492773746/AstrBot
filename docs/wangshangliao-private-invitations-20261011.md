## 安全边界

发送者身份来自原生认证消息，查询限定当前采集机器人、账号与已勾选群。
仅显示并查询当前开启返现的群，包含本人暂时没有邀请记录的群；暂停群不显示。
编号菜单绑定原账号、发送者、私聊会话、配置与群版本，十分钟有效。
群关闭、换号、配置更新或菜单群顺序变化后旧编号拒绝使用，不会悄悄改选另一群。
查询前后及最终原生发送前重新核验身份、业务代次、私聊回复开关与群范围。
SQL 参数绑定，连接使用 `mode=ro` 和 `query_only`；排除自然进群与未证实归属。
同一用户5秒限频、同一消息重复调用缓存、服务最多两项并发、限流索引最多2048项，
SQLite 查询预算1秒。取消等待不提前释放仍在执行的数据库线程名额。
工具只信任具体原生类型，不信任工具名称或模型声称的身份。
普通私聊仍禁止管理、shell、Python、文件、MCP、子代理及后台执行工具；
已有内置只读知识库工具保留原有边界。
模型调用本人查询后，最终回复采用服务端确定文本，不采用模型声称的管理成功结果。

## 默认自动同意

2026年10月13日（北京时间），根据用户明确要求接入默认开启的自动同意。
官方客户端申请列表请求为 `{"lastId":0}`；处理请求固定为原记录 `flId`、
`FRIENDLOG_STATE_AGREE`、空备注、默认分类和原记录隐私选项。
只接受 `FROM_HIM` 且 `FRIENDLOG_STATE_PROCESSING` 的申请，同意后再读取列表，
核对同一申请、同一账号和已同意状态。收到私信不会触发同意。

使用原生已登录业务连接，不另行登录；开关、冷却、申请处理意图和结果按机器人实例与账号
持久化隔离。后台「好友清理」提供开关，任何聊天身份和AI工具都没有操作入口。
每轮最多处理一条，接口之间至少3秒，同意与删除操作共用至少30秒冷却。
明确关闭、离线或业务暂停时停止；拒绝、超时、核对失败或中断后结果不明会停住，
不重试，也不能通过插件重载或切换开关清除异常锁定。

生产只读查询返回9条和112条历史申请，均已同意，没有待处理申请。
