# LajiaoLiao Platform Capabilities

The October 12, 2026 retest adds bidirectional private GIF evidence and real
20-second persistent recall jobs. Reply classification was injected by a local
acceptance tool, not a live human command. Two real idle account connections
passed a two-hour observation on v0.8.3; this does not certify real hundred-group
model capacity or live cross-platform latency. Audio, files and video remain
excluded.

This deployment supports AstrBot 4.28.1 with its matching LajiaoLiao plugin v0.8.3.
Authentication remains in the bot editor. The plugin has no login or manual sanction UI.

The entry is unchanged: Plugin Pages → LajiaoLiao Management → Capabilities.
Select the bot and group using the existing top selectors.

- Native execution evidence and complete human workflow acceptance are separate.
  Member recall and nickname synchronization are configurable but default off.
- Recall and nickname synchronization require explicit per-group grants and a native
  owner or administrator role. Existing bot and administrator protections remain.
- Unknown outcomes are not retried, and moderation never automatically kicks members.
- Unavailable-account cleanup remains blocked without authoritative account status.
  Voice, files, video, additional mentions and quoted images remain out of scope.

Previously generic pending labels now distinguish verified native actions from pending
workflow acceptance. Login, group selection and data locations are unchanged. Saves
remain scoped to one bot and group and require the current configuration version.
