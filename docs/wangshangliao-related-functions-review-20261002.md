## 本轮修复

| 问题 | 修复 | 主要回归 |
| --- | --- | --- |
| 旧关键词处罚分支不验证消息时间，补收历史消息可能增加警告或处罚次数 | 与即时对话入口共用时间检查，未知时间、超过五分钟、超前超过五秒均忽略；服务端时间优先，不使用本地接收时间 | 无效、过期、未来、零值、非有限数、服务端时间优先；拒绝时不创建处罚记录或调用处罚 |
| 关键词处罚对不完整成员目录以及查询期间撤权的检查不足 | 要求完整目录；目录查询后重新检查动作权限和自动化开关 | 目录不完整、撤销动作授权、关闭自动化均不警告或处罚 |
| 历史私信、固定命令和群内唤醒可能重新进入对话处理 | 过期或时间未知的固定命令、私信和群内唤醒静默终止，不进入命令服务或 AI；正常新消息仍按原权限路由 | 开启抽奖、自然语言创建、确认码、普通私信、群禁言、排名和群内 AI 唤醒的旧消息隔离 |
| 倒计时结束但后台尚未完成开奖时，聊天状态仍为“报名中” | 状态查询显示“报名已截止，等待开奖”；不提前修改真实开奖状态 | 截止前、截止点、开奖后；成员核验跨过截止时间不得报名 |
| 报名过期、名额满等反馈误用庆祝标记 | 只有实际报名成功使用庆祝标记；重复报名为信息提示，失败为警示 | 过期、截止、名额满、邀请门槛、身份未核验、机器人参赛和重复报名 |

## 已检查并保留的保护

- 抽奖：同一成员只登记一次；已开奖/未知结果不重抽；开奖时剔除离群、封禁、身份变化及机器人账号。报名查询使用冻结的本期参数，不把下期设置套到本期。
- 邀请奖励：只按平台可验证的入群归属计奖；待审核不计奖；现有成员建立基线；重复进出不重复计奖；新费率不改已记账或待核验记录的费率；暂停后重新启用重建基线。
- 每日排名：北京时间日界线；按消息身份去重；命令、机器人、时间未知以及已确认违规消息不计入；频率和重复内容限制保留。
- 独立审核：客服人格、知识库和群管工具不进入违规审核调用；模型异常继续走规则兜底；旧内容审核分支已有历史时间保护。
- 定时规则：重启遇到已错过边界、撤权或结果未知时暂停，不盲目补执行群禁言。
- 撤回：抽奖开始、取消、中奖名单以及报名和抽奖状态反馈保留；排名等其他已配置功能回复仍按原来的二十秒撤回策略。同步修正管理页架构表中的例外说明。
