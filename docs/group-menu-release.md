# 多群主接入与菜单体验验收

## 本次发布

独立开发分支 `feat/group-menu-experience-20261004`。仅热加载
`astrbot_plugin_superbot`，AstrBot 主进程未重启。没有开启公众接入、自动付款或新增 AI 授权。

私聊增加免费接入说明、动态加群链接和“我的群”；客服改为平台帮助、
本群业务联系和显式 AI 咨询。业务联系人支持 Telegram 用户名，
未配置时使用经营者身份链接，不显示手机号。

## 菜单对照

| 状态 | 普通成员看到的入口 |
|---|---|
| 公众接入关闭 | 分批开放说明；加群、我的群；无测试资格时联系平台 |
| 公众接入开启 | 免费群管理与积分娱乐说明；真实群主接入指引 |
| 本群已启用玩法且权限核实 | 对应游戏、积分及适用查询 |
| 本群停用、经营暂停或权限未知 | 隐藏业务入口，不承诺可用 |
| AI 未授权或预算不足 | 静态帮助、业务联系；不启动模型 |

群键盘随正常业务回复更新，不额外广播键盘说明。快捷命令和玩法大全使用
同一可用性判断；旧命令、旧按钮仍需通过服务器权限校验。

- 全框架回归：6,080 通过，6 跳过。已修复生命周期测试导致的插件模块缓存污染。

- 模拟覆盖关闭／试点／公开接入、两群独立配置、联系人越权及过期保存、
  权限未知／过期／核验失败、未授权 AI 不进入模型链路。
- 现有 Telethon 测试账号真实验证 `/start`、`/help`、客服、我的群；
  `@wdhihji1` 验证玩法大全。没有下注、付款或修改设置。
- 此轮没有在两个真实群内修改配置；双群差异与隔离属于离线模拟验收，
  不宣称完成双群真实经营验收。

群归属、钱包、逐群配置、资源授权及平台功能开关未变化。
