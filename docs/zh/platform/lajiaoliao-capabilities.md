# 辣椒聊平台能力

本部署支持 AstrBot 4.28.1 配套辣椒聊群管插件 v0.8.3。
登录仍在创建／编辑机器人；插件不提供登录或手动处罚入口。

入口不变：插件页面 → 辣椒聊群管 → 能力。顶部先选择机器人和群。

- “原生动作已验证”表示协议动作已在指定角色20测试账号执行成功，不表示
  真人自动化闭环已完成。成员撤回和名片同步可在“自动化设置”中配置，默认关闭。
- 成员撤回模式和刷屏撤回必须同时获得逐群撤回授权；自动名片必须获得逐群
  名片授权。机器人还必须拥有平台原生群主或管理员权限。
- 自动动作继续保护全部绑定机器人、AstrBot 管理员及本群授权管理员。
  未知回执不自动重试，违规处罚不自动踢人。
- 账号清理没有可靠封禁／注销接口，保持禁用，不按昵称猜测账号状态。
- 语音、文件、视频、新增 @ 与引用图片仍不在已批准接入范围内。

旧“已实现／待验证”显示现在区分原生执行证据与完整业务验收；没有迁移登录、
群选择或业务数据。保存仍只影响当前机器人、当前群，遵循配置版本检查。

2026-10-12复验新增双向私聊GIF实测和20秒持久化撤回调度证据。JPEG、PNG、
GIF以外的语音、文件、视频继续排除。功能回复的测试分类由本机验收工具注入，
不能当作真人命令闭环。v0.8.3双账号真实空闲连接观察已超过两小时；
这不是百群真实模型容量或其他平台固定负载P95验收。
