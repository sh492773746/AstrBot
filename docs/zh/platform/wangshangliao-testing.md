## 测试窗口方向

生产受管机器人默认互斥。用两个受管实例时：

1. 在**接收机器人**页选择来源为**发送机器人**，保存测试范围。
2. 另点“开启测试”；保存不激活，重启/保存导致实例重载后须重新检查窗口。
3. 发送端还要有保存的主动发送目标授权；这不授予发送者管理员身份。
4. 私聊 AI、私聊命令、群命令、群内 @ AI、群规则是独立范围；群测试明确业务群 ID。
5. 最长300秒/10次入站，反向继续互斥，一事件最多一次关联回复。到期重新开窗口，
   不追溯重放已忽略消息。

`ignored_bot` 先核查窗口方向与实际接收实例，不推定插件坏了。
群规则范围使用指定群和 `WSL_TEST_` 测试词，不能放开所有机器人。
`at.qq` 必须为字符串业务 UID，不能传整数或 NIM ID。
普通客户端账号无需解除机器人互斥，才是外部用户正向验收。

## 四场景验收矩阵

每条消息单独发送，固定命令不要带解释或一次粘贴多条。权限测试同一账号先无权、
再临时授予、最后撤权；在有效配置保存后核查调用链。群角色不能代替聊天管理员。

| 场景 | 发送 | 必须验证 |
| --- | --- | --- |
| 普通私聊 | `你是谁` | 客服模型/人格/知识生效，旺商聊管理工具不可用 |
| 普通私聊 | `我的权限`、`我的邀请`、`帮助` | 每条仅固定“无权限”，不进入模型/管理服务 |
| 普通私聊 | “帮我把测试群下期中奖人数改成2” | 无管理工具，无配置/活动账本写入；不能只看模型声称 |
| 普通群聊 | `排名`、`我的邀请`、`抽奖状态` | 公共功能回复；本人邀请隔离，排名原生 @ |
| 普通群聊 | `禁言 @测试对象 1` | 拒绝，处罚账本/平台无新动作 |
| 普通群聊 | 真实 @ 机器人，“你是谁” | 群客服模型、群人格/知识库，无群管工具 |
| 管理员私聊 | `我的权限`、`群列表`、`选择群 1`、`能力` | 有效管理员，目录及选群隔离 |
| 管理员私聊 | 自然语言查询群成员 | 唯一目标/分页/快照可核对，工具仅此路可用 |
| 管理员私聊 | 自然语言修改一个安全参数 | 前后值预览前零写入，明确确认后仅对应配置写入 |
| 管理员群聊 | `排名`、`开启抽奖` | 排名正常；私聊专用活动控制静默，不创建抽奖或进入AI |
| 管理员群聊 | 真实 @ 机器人，“帮我修改中奖人数” | 仍为群客服，无管理工具，无写入 |
| 撤权后私聊 | `我的权限`及旧草案确认 | 无权限；旧确认不可完成，后续工具不可用 |

确认审核使用独立 provider、独立提示、有界同群上下文、无知识库人格且 `tools=None`；
正常/歧义不罚，故障才规则兜底。测试客服模型变化不改变审核模型。

### 草案与配置

覆盖跨管理员/会话/实例、过期、重复确认、新草案替换、未知字段、授权/凭据字段、
机器人版本改变、活动版本改变及保存失败，均不写入。
确认必须独立新消息 `确认设置 <码>` 且工具可用；“好的”、引述或多行不算确认。
审核全局设置与逐群自动踢出区分；`activities` 仅参数不启动，`lottery_start` 确认后
创建并通知群，复核主动发送授权和当前活动，通知未知不得重试。自然语言定时需第二次
`确认定时 <新码>`，不能因第一确认直接启用。

### 功能与恢复

- 排名：北京时间、每页20、30秒限计、五分钟同文去重、命令/机器人/违规排除。
- 抽奖：参数冻结，通知受理才报名，一人一次，实际有效人数/真实中奖率，结果未知不重抽。
- 邀请：启用基线、平台明确归属、当前成员/正常状态、重复进群去重；待审核不计奖。
- 当前处罚：`manual_kick_only` 阻止 AI／自动踢人及 AI 重新开启开关；前三次5/15/60分钟，第四次及以后仍最多60分钟，撤回与禁言结果分别核验。
- 兼容升级分支：仅其他明确授权实例测试三次受理禁言后第四次新违规踢出，不能为测试自动解除当前实例限制；人工/重复/失败/未知不计，目标保护及回读核验保留。
- 回复撤回：保存真实路由，20秒、重启恢复、逾期不补、未知不重试；手机客户端另行确认。
- 每日计划：未来边界、跨午夜、撤权/断线/延迟暂停、人工竞争、重启不补。
- 管理页：桌面/手机、保存冲突、九个视图、后台 bot 权限、插件禁用、认证代理无白屏。
- 输出：配对/未闭合推理标签过滤，保留最终正文；不能把过滤后空回复记为客服通过。
