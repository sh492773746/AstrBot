# 热播 Live 登录

在插件页面 `astrbot_plugin_rebo_live/settings` 的“账号登录”中选择登录方式。

| 方式 | 操作 |
| --- | --- |
| 密码登录 | 原“登录／重新登录”入口，位于“密码登录”选项中。 |
| 验证码登录 | 填写手机号 → 获取验证码 → 手动完成人机验证 → 输入6位短信验证码 → 验证码登录。 |

点击“获取验证码”后，在弹出的“安全验证”窗口中手动完成官方验证，随后才请求短信。插件自身继续使用隔离沙箱；仅固定的官方验证文档在受控窗口内获得 Cookie 访问，不向验证窗口传入手机号、密码或 WebUI 令牌。

短信至少间隔60秒，超时不会自动重发。取消验证、验证未通过或官方SDK不可用时不会发送短信，不能绕过验证。加载失败会区分脚本不可达、加载超时和服务不可用；修复后须刷新整个 WebUI，使宿主窗口同步更新。请在页面输入验证码，不必发送到聊天中。

验证码不写入文件或日志；登录成功只保留会话令牌，并清除旧保存密码。暂停的房间保持暂停，轮播文案和间隔不变。后续会话失效需要再次人工登录，不会自动索取验证码。

页面显示“已就绪”后即可输入和切换登录方式。若一直停在“初始化”，请刷新整个 WebUI，让页面重新取得授权；无需重启插件或重新登录热播账号。页面脚本兼容 Cloudflare Access 下的沙箱加载，不关闭访问授权或放宽沙箱权限。授权失效、脚本加载失败时保留明确提示，操作不会自动重试。
