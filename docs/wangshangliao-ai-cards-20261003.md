# 旺商聊 AI 名片控制

日期：2026-10-03。

## 本次实现

1. 管理员私聊按群开启或关闭自动名片规范。`config_preview` 使用
   `target=moderation`、目标群及 `changes={"card_auto":true/false}`，仅修改该群。
   预览后同一管理员、同一私聊发送 `确认设置 <码>`，原配置版本未改变才保存。
2. 单人成员自定义群名片。通过群/成员目录快照的当前页编号选择目标，
   `card_member_preview` 仅接受 `member_number` 和 `card_name`，不能传任意UID。
   先展示群、成员、原名与新名，另发明确确认后 `card_execute` 才排队执行。
3. 私聊 `规则` 可读目标群的当前自动名片开关，查询不会创建草案。
4. 管理页“对话示例 → 私聊与权限 → 名片设置”展示静态示例。

## 安全边界

- 普通用户和群内管理员对话仍没有管理工具。
- 开启自动名片或改名需要已保存的 `rename` 授权及机器人真实平台权限；AI不能授予权限。
- 群主、平台管理员、已接入机器人、不可用账号及不确定目标继续受保护。
- 预览十分钟有效，账号、管理员和私聊绑定；同一消息不能预览后立即执行。
- 重新查询成员身份，实际写入前再校验原名及身份；成员映射改变不沿用旧快照。
- 后台任务每次写入重查管理员身份，排队后撤权也会阻止修改。
- 回执未知不盲重试；请求受理或任务排队不等于改名完成。
- 自动规范沿用现有规则（通常前两个字符及短名备用规则），不是任意命名模板；关闭不回滚历史修改。
- AI与自动踢群限制 `manual_kick_only` 保持开启，未扩展权限或清空计数。
- 审核模型、关键词、递进处罚仍为实例级，本次没有把这些配置改成逐群隔离。
