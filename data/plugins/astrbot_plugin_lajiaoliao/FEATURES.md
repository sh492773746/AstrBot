## 验收入口

在群管页选择实例与已开启群，刷新业务状态，再显式保存业务开关。保存不发送消息。管理员私聊可发送“帮助”查看命令，在已选群中管理业务。

真实业务验证只使用用户指定账号与测试群，须逐项确认开关、通知内容及目标。本轮没有默认向真实群开抽、执行每日通知或调用真实审核模型。

## 回滚

升级前代码备份：`/opt/lajiaoliao-migration-backups/20261009-business-v9v8XH/`。此目录标签使用北京时间；测试报告使用 UTC。

先停止辣椒聊消费者，再恢复备份中的插件代码。保留最新 Token、游标、固定动作回执和 `business.sqlite3`，不要覆盖整份 AstrBot 配置。新业务开启后回滚到不认识业务数据库的旧版本会暂停其后台执行，不能自动恢复未知回执或重复发布开奖结果。

需要文件级恢复时，安排 AstrBot 停机窗口，执行现有工具的插件限定模式；不恢复 Dashboard 或旧账号数据：

```bash
.venv/bin/python services/lajiaoliao-bridge/rollback_plugin_code.py \
  --backup /opt/lajiaoliao-migration-backups/20261009-business-v9v8XH --plugin-only
```

工具在 AstrBot 仍运行时拒绝交换代码。完成后启动服务，核对各账号最新凭据、游标及新业务的暂停状态。
