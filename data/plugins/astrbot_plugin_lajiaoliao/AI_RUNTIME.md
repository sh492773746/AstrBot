# AI 人格与配额

支持版本：本部署 AstrBot 4.28.1，辣椒聊插件 v0.7.0。不是任意官方版本的即装即用插件。

## 分流

群内所有人使用聊天人格。普通私聊使用聊天人格；有效群管理员私聊使用专属群管人格。
单群管理员自动定位，多群管理员需发送“群列表”“选择群 编号”。目标群必须开启 AI 群管查询。
聊天不提供管理工具；群管只调用已有固定查询和设置预览，真人确认流程不变。
普通私聊和管理私聊采用独立历史；管理历史还按群分开。旧混合历史不删除，也不自动导入。
人格和管理群由服务端授权选择，不接受聊天内容切换。管理员撤权后不能继续读取管理历史。
辣椒聊不将新消息追加到旧运行对话；每条消息独立计额并按对应会话键排队，避免切群或身份变化后混用历史。

## 默认额度

北京时间每日零点重置，每机器人独立。普通用户每 UID 20 次，群聊与普通私聊共享；
管理私聊每 UID 100 次，独立计数。每群另外共用 500 次，群聊同时通过个人和群额度。
0 停用对应 AI。调整额度不清零已用次数。固定命令、抽奖报名及规则动作不消耗聊天额度。

首次模型发起边界计一次，模型失败也计；图片描述、引用图描述、压缩、回退和工具续轮共用同一次。
回执幂等保留，不将进程重启中的未知状态当作可自动重试。日用量以请求发起时日期为准，跨午夜续轮仍算同一轮。
预检、拒绝、排队超时不计。账本写入与上游请求不可能组成分布式原子事务：
进程在发起边界崩溃时可能留下已扣但结果未知的记录，不自动退还或重发。
实际模型调用次数与 Token 单独统计；没有 usage 时标为未知，不能把次数当作固定成本。
自动审核另记模型调用，不计聊天额度。本轮不建立租户整体成本预算。
本版只支持 AstrBot 原生 local Agent；外部 Agent 未接入完整调用门禁时拒绝辣椒聊 AI，
页面显示不兼容原因。其他平台的外部 Agent 不受影响。

## 控制台

群管页面的“AI 配额”TAB选择两个人格、20/100 次实例额度及私聊提醒管理员；
当前群另设单群额度和群提醒管理员。配置使用独立版本，不修改抽奖、规则或任务版本。
`ai-config` POST读取/保存，保存带 `confirm`、`version`、`group_version` 和 `instance_revision`。
`ai-usage` POST 或 GET读取用量，分页50条。所有接口核验登录用户与绑定会话归属。
普通聊天、固定命令和模型工具不能修改这些配置。

提醒默认没有接收人，只留后台记录。群提醒必须是该群授权管理员，
私聊提醒必须是实例有效 AstrBot 管理员；发送前再次检查授权和私聊策略。
每个耗尽桶每日生成一次记录，同一接收人五分钟内合并，不向群或普通用户刷屏。
发送结果未知不重发。发送前被策略或离线状态阻止记录为 blocked，不冒称已尝试发送。
用量页显示无接收人、已阻止、已通知、失败和待核验状态；回执只保存状态与消息 ID。
跨午夜未发送的旧耗尽提醒标记 expired，不在额度重置后补发。

## 运行及升级

聊天与自动审核共用全插件最多8路AI、每实例4路；其中审核最多2路。
等待上限64，30秒超时。沿用4个数据库工作槽与64项准入。
并发队列与会话锁共用30秒预算；授权失效后在读取管理历史前拒绝。
每个账号仍使用一个Go进程；人格与额度不改变Token、游标或账号目录。
新增 `provider/event_guard.py`，以及本部署主Agent、内部Stage、
`agent_request.py` 和原生命令 `conversation.py` 的可选扩展。
原生 new/stats 命令使用相同隔离历史入口，不需要启用 AI，也不占用模型并发或额度。
核心只调用事件的可选接口；没有接口的其他平台不参与额度控制。
首次安装核心扩展需一次 AstrBot 重启，之后仅人格、额度和通知配置可热更新。

升级前运行受限备份，确认没有授权提交、运行中抽奖或临近任务，再构建并校验运行包。
回滚先停止消费者，使用 `rollback_plugin_code.py --plugin-only` 恢复旧插件代码；
保留兼容的可选核心扩展和最新账本，不恢复旧Token、旧游标或旧配置快照。
若需回滚核心，仅在服务停止时逐项对照受限核心备份，不覆盖其他平台后续修改。

只读发布工具 `services/lajiaoliao-bridge/ai_release_acceptance.py`：
重启前用 `snapshot --output 受限目录/before.json` 保存校验，重启后用
`verify --before 受限目录/before.json --output 受限目录/after.json` 核验两实例、
配置、绑定、群设置和消费者数；不提交消息、不保存配置。执行前先构建并审计校验和。

## 验收边界

真实管理员通知需明确指定接收UID；默认未指定不会发送。
离线模拟不等于真实模型或双账号长稳验收；实际成本须在选定模型与负载下测量。
SaaS尚未开放，多租户方案见 SAAS.md。
