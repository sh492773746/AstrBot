# 多群主接入与本群菜单

一个机器人，本BOT总控，群主独立经营自己的群。

## 免费接入

私聊首页和帮助提供「添加到群聊」「我的群」。公开接入关闭时显示分批开放，
普通群无需绑定凭证：将机器人加入超级群并设为管理员即自动接入。历史经营主体仍可使用绑定入口。
公开接入、广告付款单、AI预算是独立开关，宣传文字不会开启任何功能。
添加机器人并设为管理员后会自动登记本群并启用默认功能；群管理员可自行关闭。

## 群内入口

### 玩法设置与返回路径

「我的群 → 当前群 → 玩法设置」只列加拿大28、积分快三、积分转盘、老虎机PvP、扫雷接龙、双人对赌六个玩法。
点击玩法后才显示该玩法独有的参数和记录：加拿大／快三限额、转盘档位／次数／冷却、老虎机／扫雷档位与桌次核查；对赌显示近期场次及固定规则，无可自定义参数。
参数填写、取消和保存保持当前群和玩法，不再跳转到总控页面。

各详情页「返回玩法设置」返回本群六项玩法，「返回选群」回到「我的群」，不会要求全局玩法权限。
开启、关闭及每日开放时段统一到本群【功能启停】。详情页不再提供启停按钮或重复的「本群玩法总览」；旧总览和旧启停按钮跳转到【功能启停】，不直接改变开关。

### 群主／管理员独立控制

在「我的群 → 当前群 → 功能启停」仅提供六项娱乐、AI客服和制图开关，不提供本群服务、广告、积分奖励开关。
群主／现任管理员可独立控制，不能绕过本BOT总开关。AI客服和制图默认授权、默认本群开关开启，统一使用总控模型、知识、人格和固定模板，不开放群级定制。
既有总控显式停用、调用限额以及手动关闭不自动抹除；全局任务额度、个人次数、供应商配置仍生效。
现任管理员需先在目标群发一条消息，使机器人识别成员记录。每次确认实时核验 Telegram 身份，撤权后旧按钮不能继续执行；不授予收款或广告审核权限。

「功能启停 → 每日娱乐时段」只列六项娱乐，按“选择玩法 → 开始时间 → 结束时间 → 确认保存”填写。
北京时间：开始00:00—23:59，结束00:00—24:00；00:00—24:00代表全天，22:00—02:00代表跨午夜。起止不能相同，开始包含、结束不包含。
「返回上一级」回到功能启停；时段只限制娱乐的新参与，不限制广告、奖励、AI客服或制图。旧非娱乐时段值保留但不再生效。
手动关闭不会到点强制开启，已有订单结算和退款继续处理。

### 奖励与派送积分

「设置奖励」分步收集签到积分、聊天积分、聊天奖励间隔及每日上限。
积分和每日上限为0—1000000；间隔为15—86400秒，输入前显示范围，错误输入保留在当前步骤。

旧「调整成员积分」入口更名为「派送积分给群员」：
1. 发送群员 @用户名或 https://t.me/用户名，不再要求数字UID。机器人通过本群成员记录定位，并实时核验身份；未知成员请先在群里发言。
2. 核对群员信息，选择「+积分」或「-积分」。
3. 填写1—1000000的数量（扣减可填100或-100），核对预览后确认，无需填写原因。

只变更本群娱乐积分，扣减不得超过余额。确认时再次核验成员身份，积分与通知记录原子入库；重复点击不重复加减或重复创建通知。群通知展示成员、加减数量和本群剩余积分。通知发送结果未知时先查看群消息，不能通过重复派送重发。

键盘、快捷命令、玩法大全按本群启用状态生成。本BOT未允许、经营暂停、
总控显式限额用尽或机器人权限未核实的业务不会显示为可用。
旧按钮、文字命令仍由实际执行入口核权。菜单隐藏不是权限控制的替代。
键盘随正常查询回复更新，不因本次升级批量发送宣传或键盘说明。
Telegram 客户端仍使用输入框旁的原生键盘图标收起和展开。
`/bets` 和独立玩法规则不再出现在快捷菜单，玩法说明统一到帮助。

## 联系与AI

「客服」只打开分流菜单，不直接调用模型。本BOT使用问题联系本BOT；
广告审核、收款、退款及积分争议联系本群经营者，本BOT不代为担保。
私聊先选群；群内发起固定使用当前群，不沿用其他群选择。

群管理员可在「我的群 → 当前群 → 本群业务联系」设置 Telegram 用户名或用户链接，
经过预览确认后仅对本群生效。手机号及任意外部链接不接受。
未设置时使用经营者身份链接；链接无法访问时回原群联系群主。

AI默认授权并使用本BOT统一模型与知识；显式停用或达到总控限额时不调用模型。选择群后发送 `/chat`
开始原有咨询会话。切换客服入口会结束旧会话，旧消息不会自动使用新群预算。
群管理员不能修改本BOT总开关、授权、密钥、赔率、概率、抽水。
# 发布与知识库

已有实例热加载不自动上传知识文档，避免触发嵌入模型计费。静态帮助及客服知识源文件同步更新；向量索引更新需维护者单独授权执行。
# 接入归属修正（2026-10-06）

管理员邀请机器人不等于获得经营归属。首次接入从 Telegram 管理员列表核验
真实群主后登记经营者；核验失败不猜测经营者。普通群管理员仍按实时权限管理本群。

历史自动接入误登记时，由 Telegram 本群现任群主或管理员私聊打开「我的群 → 当前群 →
确认经营归属」。管理员可以代为确认，但经营者始终登记为实时核实的 Telegram 真实群主，
不会变为操作管理员。确认时再次核验操作者、群主、机器人身份及配置版本。存在历史广告订单、收款地址、
广告位或付款单时禁止自助转移，须人工核查；不迁移资金、订单或收款资料。
确认归属不自动恢复服务。退群后暂停的群还须另点「确认重新接入」；
语义采集、定时管理与待核查广告不会自动恢复。本群现任管理员可以确认恢复基础服务，
但不能绕过总控暂停、群主变更核查，也不因此获得收款或订单经营权限。
