# 多群主接入与本群菜单

一个机器人，平台总控，群主独立经营自己的群。

## 免费接入

私聊首页和帮助提供「添加到群聊」「我的群」。公开接入关闭时显示分批开放，
只有测试名单内的真实群主可取得绑定凭证；未开放用户可联系平台管理员。
公开接入、广告付款单、AI预算是独立开关，宣传文字不会开启任何功能。
添加机器人、设为管理员后仍需完成绑定并选择本群功能。

## 群内入口

键盘、快捷命令、玩法大全按本群启用状态生成。平台未允许、经营暂停、
预算不足或机器人权限未核实的业务不会显示为可用。
旧按钮、文字命令仍由实际执行入口核权。菜单隐藏不是权限控制的替代。
键盘随正常查询回复更新，不因本次升级批量发送宣传或键盘说明。
Telegram 客户端仍使用输入框旁的原生键盘图标收起和展开。
`/bets` 和独立玩法规则不再出现在快捷菜单，玩法说明统一到帮助。

## 联系与AI

「客服」只打开分流菜单，不直接调用模型。平台使用问题联系平台；
广告审核、收款、退款及积分争议联系本群经营者，平台不代为担保。
私聊先选群；群内发起固定使用当前群，不沿用其他群选择。

群主可在「我的群 → 当前群 → 本群业务联系」设置 Telegram 用户名或用户链接，
经过预览确认后仅对本群生效。手机号及任意外部链接不接受。
未设置时使用经营者身份链接；链接无法访问时回原群联系群主。

AI使用平台模型及逐群授权预算。未授权不调用模型；选择群后发送 `/chat`
开始原有咨询会话。切换客服入口会结束旧会话，旧消息不会自动使用新群预算。
群主不能修改平台总开关、授权、密钥、赔率、概率、抽水。
# 发布与知识库

已有实例热加载不自动上传知识文档，避免触发嵌入模型计费。静态帮助及客服知识源文件同步更新；向量索引更新需维护者单独授权执行。
