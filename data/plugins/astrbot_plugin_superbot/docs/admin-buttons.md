# 管理按钮操作

广告投递菜单统一为“发布广告”和“我的广告”。我的广告按订单显示投放群名和置顶/普通类型；详情返回订单列表，广告位选择返回广告菜单，不重发欢迎语。原供应、需求历史订单仍保留。

广告配置统一称为“广告位”。价格、置顶名额及积分奖励提供常用数值按钮，同时支持自定义输入。发布群从群管理中已启用的群分页选择，每页8个；没有可选群时须先完成群管理设置。确认保存时再次检查群仍启用。内部字段及历史订单快照保持兼容，不迁移或重写旧订单。

私聊「管理」中，房间开关和限额分别操作。积分奖励、广告广告位、授权和人工积分调整使用逐项向导，不再要求一次发送整串参数。

开关、广告类型、广告期限和授权范围使用按钮。金额、积分、用户数字 UID、群数字 ID、名称和说明逐项输入。每步可返回或取消；最后核对后点击确认才保存。授权仍仅限首位超管签发，最终保存仍重新检查权限。

授权目标支持数字 UID、`@用户名`、`t.me/用户名` 和 `https://t.me/用户名`。
用户名方式要求对方先私聊机器人发送 `/start` 建立记录；通过已知 UID 查询当前 Telegram 私聊账号，
不使用显示名、邀请链接或消息链接猜测身份。记录缺失、重复、用户名变更或查询失败时拒绝签发，
可让对方重新发送 `/start` 或改用已核实的数字 UID。
确认页显示最终 UID，点击确认再次核对用户名与该 UID 一致；权限和十分钟领取链接仍绑定 UID，
其他用户不能领取。数字 UID 入口、权限范围和有效期规则保持不变。

新授权向导统一提供“全功能”业务管理员：广告、积分、模拟28、全部已登记群、
群配置模板、头像管理和功能启停均可操作。授权有效期仍由首位超管选择。
生成任何授权链接（包括指定群授权）及撤销他人权限仅首位超管可操作；
菜单隐藏且后端拒绝旧按钮或直接调用。全功能管理员不能授予、续期或收回权限。
所有群操作仍检查 Telegram 实际管理身份和权限；不授予服务器或 AstrBot 后台账号权限。
历史分模块授权保持原范围，不自动升级；首位超管可撤销全功能管理员，到期也自动失效。

开奖采集与模拟28总开关、房间开关相互独立。后台插件配置的 `keno_fetch_enabled` 关闭时不会发起采集，页面显示“采集未开启”。`keno_proxy` 用于采集专用代理，凭据仅在后台配置。源站返回403代表请求被拒绝，不表示没有开奖；需验证代理或来源访问条件，不能编造结果。配置采集不应自动启用下注。
