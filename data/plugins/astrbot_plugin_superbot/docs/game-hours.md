# 加拿大28：所有群统一开放时间

私聊「管理 → 模拟28管理 → 所有群开放时间」：

- 全天开放：默认行为，与升级前相同。
- 每日定时：按钮选择开始小时、分钟，再选择结束小时、分钟，支持跨午夜。
- 暂停开放：停止新下注，已受理的订单继续结算。

固定北京时间；开始时刻包含，结束时刻不包含。起止相同不能保存，
需要全天开放时直接点“全天开放”。每个时间段每天重复，无需进程常驻定时边界任务。
确认后立即按当前时间生效；不会开启原来关闭的游戏模块、倍率或群连续播报。
不修改已有赔率、积分限额、群倍率选择、积分账本或开奖采集。

沿用 `game` 业务管理权限，只有具有模拟28管理授权的用户或首位超管可配置；
仅拥有群管权限不代表可修改全局时段。普通用户及群内不提供设置入口。
确认绑定操作者、私聊及配置版本，单次使用；旧按钮、撤权后的按钮均拒绝执行。

`game_hours` 设置保存模式、开始和结束时间；版本使用现有 settings.version。
每次下注预览和真正扣分前，在当前实例时间和事务中检查时段。所有群共享该设置，
不能通过旧确认、旧 /game 入口或其他群绕过。重启不补投错过的期次。

休息期间不创建新开盘公告，待发送开盘再次检查；已有开盘页更新为休息状态。
已有受理订单的封盘与结算继续；不为无人下注的休息期继续发布空开奖结果。
恢复开放只接入当前可验证期次，不补发旧开盘。已受理订单和开奖采集不依赖时段开关。

隔离测试覆盖跨午夜及边界、全局权限和确认版本、旧按钮、待发公告、
下注扣分前检查和休息期间正常结算。默认全天开放，无需迁移历史订单。
回滚不还原数据库；旧版不认识时段门禁，回滚前应关闭游戏总开关，避免意外全天受理。
