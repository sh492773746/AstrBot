# 广告 USDT 余额

USDT余额仅用于广告消费，不可用于真实投注，不可兑换模拟下注积分。加拿大28只使用签到等途径获得的娱乐积分。

“我的 → 充值 USDT”输入整数金额，确认生成充值单后，按单上全部6位小数的精确金额向指定地址转入 USDT-TRC20。每单30分钟，最多同时三单；实际到账金额含小数尾数，全部计入广告余额。平台不收取此尾数为手续费；转出网络手续费需额外承担。

只有订单创建后的转账、正确网络和官方 USDT 合约、精确收款地址和金额、成功且已固化的链上回执才自动入账。地址历史转账不会自动归属新用户；仅凭交易截图或提交交易哈希不能认领充值。金额终身不重复分配。此方案适用于支持6位小数精确转账的钱包；不能精确转账的平台请勿使用。

到账通常需等待链上确认及下一次查询。超时到账、金额不符或多笔合约转入保留待核查，不自动退款或重新分配。请联系管理员并保留订单编号；不要重复转账。账户余额不支持提现、转账，也不兑换加拿大28积分。

USDT广告套餐订单可用广告余额支付，需用户再次确认，扣款与付款状态在同一事务提交。仍需管理员审核内容；审核驳回自动退回广告余额。已发布、停止排程及发布结果未知不会自动退款，须人工核查。其他币种套餐继续原有核款流程，不做隐式汇率换算。

## 运维

配置项 usdt_address 为公开收款地址，usdt_enabled 控制创建充值单；trongrid_api_key 为查询密钥，后端保存不回显，不能填写私钥。服务不持有私钥，不签名、不归集、不提现。关闭充值后仍核验已有订单。

独立表 ad_wallets/ad_money/deposits/chain_events/ad_payments，与积分完全分开。金额使用整数微USDT。每60秒从首次启用扫描时间起按确认转入分页查询，逐笔用 walletsolidity 回执验证 Transfer 日志；完整证据保存在 chain_events。失败不跳过扫描窗口，查询故障或健康记录超180秒时不创建新充值单。高交易量超过扫描上限会停止新充值并要求运维处理；待核查及历史审计不自动删除。

监控 settings.usdt_health、未匹配 chain_events、逾期 deposits 及磁盘容量。TronGrid 公共接口可能限流；持续业务应配置查询 API Key。未知款项的归属与退款仅人工核实，不提供凭交易哈希自助认领。

备份代码、配置与SQLite一致性快照。资金上线后不能直接恢复不识别 ad_wallet 付款的旧版广告代码；回滚必须先停用广告发布与新充值，保留新版对账能力或迁移至兼容版本，不能恢复整库覆盖资金流水。模拟测试和主网只读回执验证不代表真实充值全链路已验收；首笔小额实际充值需核对订单、到账和广告消费流水。
# 充值二维码

生成充值单后点击“收款二维码”，可获取该订单收款地址的 PNG 二维码。二维码仅包含地址，不包含网络、币种和金额；交易所扫码兼容性由其客户端决定。必须选择 USDT-TRC20，核对扣除手续费后的实际到账金额与订单六位小数完全一致。订单过期或已到账后不再生成二维码；已经发送的图片无法自动失效，付款前须核对原订单有效期。二维码仅向订单本人提供。
