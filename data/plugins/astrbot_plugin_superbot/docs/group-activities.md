# 群活动、统计与指定群管

## 使用入口

私聊仅保留「我的群｜帮助｜客服」。选择本群后进入排行榜与统计、活动管理、命令与交互或指定群管。活动不是游戏，不加入玩法大全。

群内：`/points_rank` 积分前20名与本人排名；`/stats` 今日活跃；`/stat_week` 本周；`/stats 起始日期 结束日期` 自定义，最多31天；`/lottery` 打开活动面板。`/stat` 兼容今日统计。键盘帮助与 `/help` 使用同一份玩家帮助。

## 权限边界

当前 Telegram 群主自动可管理；其他人必须同时是当前管理员且得到当前群主的本BOT授权。指定群管不能继续授权。总管不是本群管理者时，不获得业务权限。

权限证明绑定实例、异步任务、操作者、目标群及群／经营主体版本。按钮、草稿与确认重新查询 Telegram；撤权、退群、群主变更或版本变更后拒绝旧操作。未登记群不放行。维护 Web 页面不提供绕过 Telegram 核验的群业务接口；服务器权限不在应用隔离的保障范围。

## 逐项创建

1. 活动类型：活跃排行或达标随机。
2. 标题（最多60字）、说明（600字）。
3. 北京时间开始时间，或“现在”。
4. 持续分钟数：5分钟至30天。
5. 标准或严格计数；最低1—100000次。
6. 是否要求主页挂链；需要时单独填写群链接。
7. 每条消息填写一个奖品，最多50名，每项200字，可重复上一项。
8. 完整预览，确认发布。

只有取得公共面板消息ID后活动才生效。“现在”以确认送达的时间起算；指定时间保持固定。发布后规则不可修改；变更须说明原因，取消后重建。每群最多一项未结案活动，允许多个草稿。

## 统计和开奖

标准：文字或图片说明中至少有一个字母、汉字或数字。严格：另需5个有效字符、3个不同字符，同人30秒最多1条。两套计数并行保存，活动冻结选用一种。

同人同群同日标准化重复文本只计一次。机器人、匿名身份、转发、服务消息、命令、游戏操作和已识别下注不计。编辑不新增，重复更新幂等；本BOT确认删除违规消息可扣回计数，但不会重排已经冻结的候选。

两类活动都需报名。排行按次数降序，同次数按较早达到者、数字UID排序。随机活动在达标报名者中等概率生成完整候选及候补顺序，并永久固定该次顺序；刷新、重启、拒绝候选均不重抽。

主页挂链采用人工审核，不读取简介、不使用模型，不声称保留截止时的主页快照。审核通过、拒绝或暂缓；拒绝须原因及确认。前序未审核候选不得被跳过，人数不足的奖品显示空缺。确认后新发获奖通知，@获奖者；兑奖记录为待发放、已发放、放弃或争议，不改动任何钱包。

## 多机器人与欢迎消息

兼容模式接受裸命令和明确指向本BOT的命令；严格模式忽略裸斜杠命令。回复外部机器人的“取消”、数字或下注文字不进入本BOT业务；明确 `/命令@本BOT` 例外。独立广告安全检查不因此关闭。外部指向消息不得进入本BOT模型请求。

首次私聊与首次入群复用本地欢迎图，不调用生图接口；图片与说明同条发送。按钮使用当前机器人身份，只导航、不授权。已知欢迎消息可更新，重复事件去重；未知发送进入核查，不盲目补发。

## 存储和投递

`activities.py` 管理 `ga_config`、每日统计、脱正文收据、活动快照、报名、固定候选、审核、兑奖与投递队列；`activity_ui.py` 负责私聊向导和公共查询；`group_authority.py` 负责实时权限；`command_router.py` 先判定消息归属。

普通收据保留7天，仍供活动使用的证据不提前删除；每日统计和已结案活动90天，进行中、待审核或未解决兑奖争议保留。只保存标准化摘要哈希和计数，不保存普通聊天正文，不批量回填。清理按批执行。

先登记发送意图，再提交网络请求。明确限流等待；未知发送留待核查，不重复通知或重抽。已知面板编辑可安全重试。最终获奖消息默认保留24小时，个人反馈10秒。后台生命周期复用插件任务管理。

## 发布门槛

既有群新增活动默认关闭，由本群管理选择启用；新接入群沿用免费默认策略，不自动创建活动。不更改积分、赔率、付款开关或其他群配置。

完整 Superbot、适配器回归及 Ruff 通过后才可备份、插件级热加载。Telethon 先以只读脚本核实实际账号、`@wdhihji1` 和机器人当前权限；只能测试标注“不兑现”的活动。不用模拟结果冒充真实验收，不直接调用删除、转账或开奖接口代替插件链路。

回滚先关闭新增入口，保留活动及投递状态、候选、兑奖和审计；不覆盖数据库，不重抽。
