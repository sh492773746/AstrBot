# 超管群配置模板

适用于已经登记并启用的 Telegram 超级群。只在首位超管的私聊显示入口；不会因为使用模板而获得任何系统或群管理权限。

## 最快开始

1. 私聊机器人，点「群管理 → 选择群 → 超管群配置模板」。
2. 点「套用内置基础模板」，查看目标群、功能开关及替换范围。
3. 点「确认套用到本群」。需要微调时，返回该群各功能入口修改即可。

内置模板开启：举报、欢迎、群规、常用说明、人工警告入口。不会启用广告杀手、10人自动审理或任何新处罚规则；目标群原有的这些设置保持不变。全局模块未开启时，对应功能仍不可用，模板不会替你打开全局模块。

加拿大28周期公告已停用，模板不再启用或复制历史播报开关。

## 保存自己的标准配置

1. 先把一个参考群的欢迎、群规、说明、开关和广告杀手配置好。
2. 进入该群的模板入口，点「将本群保存为我的模板」。
3. 查看预览，确认保存；这一步只保存模板，不修改参考群，也不发测试消息。
4. 换到另一个已启用群，点「套用我的超管模板」，核对差异和处罚影响后确认。

每个机器人实例保存一套“我的超管模板”。再次保存会替换模板，旧版预览随即失效。保存后源群的后续改动不会自动同步到模板；模板改动也不会自动同步到已套用的群。

## 复制与保留范围

| 项目 | 内置基础模板 | 我的超管模板 |
|---|---|---|
| 举报、欢迎、群规、说明、警告入口 | 开启并填入内置内容 | 复制参考群的开关和内容 |
| 加拿大28周期公告 | 不启用 | 不复制 |
| 广告杀手总开关、检测项、关键词、处罚及累计升级参数 | 保持目标群原状 | 复制参考群设置，预览列明处罚 |
| 账号、域名、Telegram 链接白名单 | 保持目标群原状 | 保持目标群原状 |
| 日志频道与日志启停 | 保持目标群原状 | 保持目标群原状 |
| 入群验证目标和启停、每日定时禁言 | 不复制 | 不复制 |
| 10人举报AI自动审理 | 不复制 | 不复制 |
| 管理员、授权群范围、授权有效期 | 不复制 | 不复制 |
| 广告位、收款地址、充值、余额、积分奖励、赔率及限额 | 不复制 | 不复制 |
| Token、代理、模型、人格、知识库和系统权限 | 不复制 | 不复制 |

“人工警告入口开启”不等于“自动升级处罚开启”。我的模板若包含已启用的广告杀手或累计升级，预览会列出规则、阈值及处罚：命中后可直接执行，可能误判。踢出允许重新加入；封禁须先解除，且可能影响目标历史消息。必须由超管明确确认套用。

## 权限和安全

- 首位超管仍须是目标群的 Telegram 管理员，机器人也须具备对应权限。
- 套用已启用的广告杀手时核验删除消息权限；涉及禁言、踢出、封禁或相应累计升级时，额外核验限制成员权限。
- 仅处理已启用超级群，不自动加入、提升机器人权限或启用未登记群。
- 确认绑定超管 UID、私聊、目标群、模板版本与各目标配置版本；10分钟有效、仅用一次。
- 群被停用、权限撤销、配置改变、模板替换或确认过期后，必须重新预览。
- 广告杀手有未知操作待核查时，模板不能清除故障或强行恢复自动执行。
- 套用只写配置，不执行历史处罚、不补投、不改余额。已有业务义务继续按各模块规则完成。
- 导航、查看正文和取消不会写入配置。

## 存储与维护

实现：`group_template.py`；入口：`moderation_ui.py`。

模板保存在当前实例 SQLite 的 `settings.owner_group_template`，使用该记录的递增版本。确认回调复用 `callbacks`；套用更新 `cm_config`，自定义模板必要时更新 `ak_policies`，在同一个 SQLite 事务内完成，不再修改 `gb_policy`。取得群管锁后再取得历史播报锁，事务内不访问网络。

审计事件为 `owner_template_capture`、`owner_template_apply`，记录目标群、原配置和模板快照。没有自动“回滚所有群”按钮；误套用时按审计逐群恢复或重新配置，不恢复整库覆盖订单及新流水。

升级保持原模板和已套用群配置。回滚代码前停止插件任务，保留新增设置及审计；旧版不能管理新模板，但不得清空模板数据。

专项测试：`tests/test_superbot_group_template.py`，覆盖分权、旧版本、超时、跨群保留字段、权限变化、待核查保护和事务回滚。
