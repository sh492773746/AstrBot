# 大海传媒超级机器人使用知识

本页为简明兼容资料。实际玩家帮助来自 `player-help.md` 与 `player-services.md`，维护文档不导入玩家知识库。

## 入口与群管理

私聊 `/start` 显示「我的群｜帮助｜客服」。游戏在群内使用；私聊不下注、开桌或抽奖。`/cancel` 取消当前填写，不撤销已受理订单。个人真实资金钱包、充值和余额支付入口已移除，不引导用户充值。

机器人加入超级群并设为管理员后登记群。当前群主自动管理；其他人必须同时是现任Telegram管理员、获当前群主指定。指定群管不能转授权。总管角色不能代替目标群管理身份，撤权、退群或群主变更后旧按钮和未提交草稿失效。

「我的群 → 当前群」管理本群功能、奖励、玩法、广告、收款、客服联系、键盘、排行统计与活动。每步只填写一个值，最终确认后生效。各群积分、记录、订单和设置独立；赔率、概率、抽水及统一撤回策略不由群管修改。

## 群内常用操作

`/help` 与键盘「帮助」相同；`/points` 查询本人本群积分，`/checkin` 签到。积分不能提现、购买、转账或兑换广告。签到及聊天奖励按本群规则，重复、过短、命令和转发不获聊天奖励。

加拿大28发送 `加拿大`、`Canada`、`jnd`，积分快三发送 `快三`、`k3` 或点击玩法入口，建立本群本人30分钟房间。后续下注仅归当前房间，不因解析失败切到另一玩法。`取消`、`退出` 静默退出房间，不取消订单。

`历史`、`流水/ls`、`输赢/sy` 按当前房间查询；未激活需先选择。可用「加拿大历史/流水/输赢」和「快三历史/流水/输赢」明确查询，无需切换房间。积分仍是本群共同钱包。

群键盘由群主或指定群管主动开启；Telegram输入框旁的原生按钮收起或展开。功能是否开放以本群实际状态、时段和权限为准。

## 排行与群活动

`/points_rank`：本群积分前20与本人名次。`/stats`：今日活跃；自定义 `/stats YYYY-MM-DD YYYY-MM-DD`，最多31天。`/stat`、`/stat_week` 仅兼容。`/lottery`：本群活动。统计按北京时间，自本群开启后开始，不批量回填历史。

标准统计有效文字或图片说明；严格另需至少5个有效字符、3个不同字符，同群同用户每30秒最多一条。两套并行计数，活动发布时固定模式。同日同用户重复文本一次；机器人、匿名、转发、服务消息、命令和下注不计。编辑不新增，不保存聊天正文。

活动可选「活跃排行奖励」或「达标随机抽奖」，均须点击报名；报名后可计入活动开始以来的有效发言。每群最多一个已发布未结案活动，奖品仅文字说明，由管理员人工兑现，不自动转账或派发积分。

截止固定报名、计数及完整候选顺序。排行同次数按较早达到者、数字UID排序；随机为等概率且保存候补顺序，不因刷新、重启或拒绝重新抽取。主页挂群链接仅人工核验，不采集简介、不调用AI。审核通过、拒绝、暂缓；拒绝后按固定顺序递补，奖品不足时空缺。兑奖可记录待发放、已发放、放弃或争议。

## 与其他机器人共存

兼容模式支持 `/help` 和 `/help@本BOT`；严格模式群内只收明确带本BOT用户名的斜杠命令。指向其他BOT的命令、回复其他BOT的普通文字不进入本BOT查询、设置、游戏、退出或模型调用；明确 `/命令@本BOT` 例外。广告安全检查独立运行。普通聊天没有匹配就静默忽略。

## 广告、客服与异常

广告投递先确认目标群、收款方和广告位，再提交审核。独立直付订单按本群地址直接支付USDT-TRC20；实际金额含识别尾数，以订单快照为准。地址更换不影响旧单；少付、多付、迟付、证据不足及未知发布均待核查，不自动重复收费或发送。

不提供私钥、助记词。退款由本群经营者人工处理，付款人确认退款地址，系统仅记录申请及凭证，不自动转账。客服先确认目标群；本BOT帮助负责使用和故障，本群广告、收款、退款、积分争议联系对应群管理员。AI及制图不因打开说明或活动自动发起付费调用。

发送结果不明时先核查原消息、订单或对应记录，不能反复提交。删除的消息无法恢复。系统不能编造开奖、代管理员审核、代用户付款或自动兑现文字奖品。
