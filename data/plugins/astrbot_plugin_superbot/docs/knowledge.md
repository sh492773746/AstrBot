# 大海传媒超级机器人使用知识

私聊机器人发送 /start 打开底部菜单。仅显示已启用功能；个人中心查询余额、流水、广告订单、下注和追号。/cancel 退出填写。消息内按钮十分钟有效，属于原用户和原私聊，不能转发代用。

广告发布：选择供应或需求、套餐，第一行输入联系方式、其余行输入正文；核对预览后确认。按照订单内收款说明付款，再提交交易信息或图片凭证。广告需要管理员核实真实到账及审核内容后才能发布，截图不自动核款。价格和收款方式以订单快照为准。

普通广告按次发布；置顶期限由管理员选择连续30天或一个日历月。一个日历月为从生效时间加一个月，同日不存在则取月末；不保证始终是客户端最新置顶。多个广告可共存于置顶列表。到期只解除本广告置顶，不删除正文。有效广告可创建独立续期订单，付款及审核后延长原到期日，不重复发布。

积分由启用后的签到与指定群有效聊天获得。签到按北京时间自然日一次。聊天至少5个有效字符，汉字、字母和数字计数，空格和标点不计。重复、过短、命令和转发不获得聊天奖励；存在最低间隔及每日上限。具体数值由管理员设置。积分本期不可充值、提现、转账或兑换广告；未来商城尚未开放。

模拟28：在已启用超级群单独发送 jnd、加拿大 或 Canada，激活本人在当前群的文字下注30分钟，再发 大10 或 ds30xs30bz20。无需确认，整条校验成功后原子扣分；bz是豹子，b无效。发送 退出加拿大 静默退出。封盘、数据异常、消息过期或跨期不能下注；新追号不开放。扣分、结算由程序完成，不通过AI聊天执行。

管理权限：只有后台绑定的首位超管能签发授权链接。链接仅指定用户可在私聊确认领取，十分钟有效、一次使用。业务管理员只能管理获授权模块，不具备AstrBot系统权限。普通群管理员不会自动拥有机器人业务管理权限。

遇到“待核查”或未知发送结果，查询订单和流水，不反复提交。开奖结果延迟时等待真实数据；不要要求机器人编造结果。需要人工处理的付款、驳回或退款联系管理员，机器人不会自动进行金融转账。
# 广告维护更新（v1.3，以本节为准）

满位允许付款排队，按付款和审核均完成的先后展示；新广告展示期从成功发布并置顶起算。未发布订单的用户本人和广告管理员均可取消：广告余额原路退回，人工核款需人工退款登记，测试免付款不退款。未知发布结果须先核查，不直接退款或重发。

管理员可在广告管理设置广告栏统一容量、查看待核查广告栏和充值核查。位置编号保持稳定。待核查恢复需要人工确认目标消息的正文和置顶状态；客服不能替管理员确认。新菜单“已付款待处理”“展示中”“未付款”“待核查”分别显示对应订单。详情显示北京时间到期时间和退款状态。

## 群公开服务（由该群管理员逐项开启）

积分查询：群内发送“积分”“积分查询”或 `/points`，无需激活下注，仅查本人在当前群的积分。积分、签到、聊天奖励及下注结算按群独立，群间不互通。私聊可选群查余额和流水；签到请到对应群发送 /checkin。引用原消息回复，成功发送后约10秒撤回，原消息保留；连续查询保留5秒冷却，不扣分、不下注。

群内“历史”查最近10条无冲突开奖记录，约60秒撤回；“签到”与 /checkin 都领取本群签到奖励，约10秒撤回。`dd` 表示大单。引用回复均显示实际发送者 @用户名，无用户名时使用可点击称呼。开奖结果与结算名单合并展示，约30秒撤回。

加拿大28只接受激活后的新发普通文字下注；不接收按钮、斜杠下注命令、编辑、转发或匿名身份。激活成功后引用原消息回复当前期号、具体状态及剩余有效时间；期号无法核实时明确提示，不猜测。激活回复与下注反馈都在成功发送后约10秒撤回，原消息不删；不发开盘、倒计时、封盘公告；仅本群当期有人下注且全部结算后发布最终结算名单，约30秒撤回，无人下注不发。反馈结果不明时不盲目重发，查记录核对。`/checkin` 签到，`/points` 展示积分，`/bets` 查询本人订单（仅本人可见，约10秒撤回）；私聊保留记录查询。`/rules` 和 `/notes` 显示公开内容。回复普通群员原消息发 `/report` 直接受理，机器人自己的提示消息不能举报。管理员开启10人自动审理后，同一消息满10位不同有效举报人，可由AI核验违规后直接撤回；不是10条重复举报，也不自动踢人。

群内回复消息发送 `/report`，再点按钮到机器人私聊选择原因、确认提交。举报不会直接处罚对方；到「我的 → 我的举报」查看结果。举报人身份不向普通成员或日志频道公开。

群规用 `/rules`，常用说明用 `/notes`，也可从私聊「帮助 → 群规与说明」选择自己所在的群。未开启时会提示，不代表所有群都提供这项服务。入群欢迎可能附带群规按钮；有入群验证时先按提示加入目标频道或群，再点验证。

「我的 → 我的警告」只显示自己的记录；有异议请联系该群授权管理员核查。撤销警告不会恢复已删除消息或自动解除禁言。客服可以解释公开用法，但不能查看他人举报、证据或授权详情，也不能代提交、代确认或执行群管理。

## 多群主与独立收款

同一个机器人支持多个独立经营群。真实群主通过私聊「我的群 → 接入群」取得凭证，再在目标超级群验证。公众接入默认关闭，验收阶段仅向平台指定的测试群主开放；不能把实现完成解释为已经公开上线。

每群积分、奖励、玩法配置、广告位和订单独立。群主只能管理自己的群，不获得平台授权、总开关、赔率、概率或密钥权限。机器人退群、权限不足或群主身份变化时暂停新操作，保留历史订单与账本。

群主直付广告采用“提交内容 → 群主审核 → 付款单 → 核实到账 → 发布／置顶”。USDT-TRC20 直接支付到对应群主确认的地址，不经过平台广告余额或游戏积分。付款单30分钟有效，实际金额包含最多0.000999 USDT识别尾数，须按订单金额付款。广告展示时间从实际发布成功开始。

平台旧广告余额只能支付平台业务，不能抵扣其他群主的广告。地址更换只影响新付款单；旧单保留原地址、价格和内容快照。少付、多付、迟付、错误币种、多个候选交易或结果不明均须核查；客服不能宣布核款成功或代替群主退款。

只填写公开收款地址，不提供私钥、助记词或交易所登录信息。地址格式正确不代表钱包归属已获证明。退款由群主自行处理；退款地址由付款人确认，系统仅登记申请及核验链上凭证，不自动转账。

新接入群默认不能使用付费AI客服和制图。平台另行授权独立调用上限后才可使用；预算不是积分或金额，用完即停，不能转给其他群。真实到账验收和公众开放状态必须以实际管理状态为准。
