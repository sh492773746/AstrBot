# 广告审核与合并置顶

## 频道广告

机器人收到入群、加入频道或自身权限变化事件时，会检查所需权限。群聊优先在群内提醒，发送失败则私信首位超管；频道提醒发至首位超管私聊。超管须先与机器人建立私聊，否则 Telegram 可能拒绝投递。相同缺失24小时去重，不同缺失10分钟限频；无权限变化事件不主动轮询。移除机器人不再发提醒，恢复权限清除缺失状态。操作入口仍实时校验权限。

设置流程：将机器人设为频道管理员并授予发布、编辑消息权限 → 私聊管理 → 广告管理 → 广告频道 → 添加频道 → 输入数字ID或公开频道链接 → 确认启用 → 设置广告位时选择该频道。频道邀请事件自动发现目标，但不会自动启用；旧频道可手动添加。启用者还须拥有该频道对应权限。

启用频道与群聊共享广告位设置、付款、审核、合并置顶及文案编辑流程；频道不提供群员禁言等群管功能。我的广告显示频道名称。发布、修改及到期操作检查机器人权限，权限丢失显示错误并停止请求；不会将失败标记为成功。频道实际发布验收需经用户授权选定测试订单，自动测试仅使用模拟接口。

已发布或生效中的广告可由广告管理员反复修改：审核订单 → 已付款 → 选择订单 → 修改已发布文案 → 发送完整正文 → 确认保存。确认即管理员批准此次新文案，直接编辑原消息；付款、到期时间、消息ID和置顶保持不变。合并栏只替换选中广告的正文。过期、执行中或待核查订单不可修改；并发旧预览拒绝覆盖新文案。未知结果不自动重试，需核对群内消息与审计。

审核订单默认显示已付款分类，未付款可切换查看。用户名来自用户与机器人实际交互，仅作显示，不用于授权；未取得用户名或未设置用户名时显示数字 UID。

管理员可修改待处理订单正文，保存时保留付款状态、记录前后文案并撤销内容审核，必须重新预览确认。旧文案的审核按钮不能批准新文案。未付款订单可审核内容，但绝不因此发布；人工核款必须提供真实到账依据，不能用作测试发布捷径。

启用内部设置 `ad_board_enabled` 后，新置顶广告按目标群合并为一条由插件发送的广告栏，用分隔线和广告位编号展示。编号按当前显示顺序排列。新订单须通过内容审核及付款验证，受到订单广告位名额限制。单条广告栏预留3900个 UTF-16 单元；新文案放不下时保留待处理并显示原因，不截断内容。普通广告保持独立发布。

部分广告到期或停止时编辑广告栏移除相应内容，剩余广告继续置顶；全部到期时改为暂无有效广告并取消这条消息置顶。不会编辑其他管理员的置顶消息。原先独立发布的历史广告仍按旧方式到期。续期沿用原订单消息，合并栏下一轮更新内容。

发送、编辑、置顶请求前持久记录操作；超时、断线或重启中断后广告栏进入待核查，不自动重发。维护人员须核对 `ad_boards` 状态、消息 ID、实际群内内容及审计记录后人工处理，不可直接清空状态重试。

回滚须先停止广告任务，保留新增表和审计。已有合并栏时不可直接关闭合并模式运行旧版到期任务，否则旧版可能取消整个共享消息的置顶；须先人工核对并迁移有效广告。不要恢复整库覆盖上线后订单。
