🤖 **大海传媒超级机器人**

为群聊提供管理、积分奖励、娱乐玩法与个人记录查询。

🏪 **管理自己的群**
将本BOT加入超级群并设为管理员，在「我的群」选择目标群，逐步设置功能、奖励、玩法时段和业务联系信息。群主自动可管理；其他管理员须由群主在「指定群管」明确授权，不能转授权。身份会在每次操作时重新核验。

🎉 **群运营活动**
「我的群 → 本群 → 排行榜与统计／活动管理」可查看本群积分、活跃排行，并逐项创建活跃排行奖励或达标随机抽奖。奖品由群管理员人工兑现，不自动转账或派发积分。截止后人工审核资格、按固定顺序递补，再确认公布；私聊不报名。

🎮 **群内使用**
支持加拿大28、积分快三、积分转盘、老虎机、扫雷接龙及对赌。请在群内发送「帮助」查看用法；私聊不参与游戏。

💰 **积分与查询**
积分按群独立，仅用于群内娱乐。在群内发送 /my 查看个人入口；积分、签到、历史、流水和输赢均在对应群查询。本BOT不提供个人资金钱包或充值余额。

💬 **联系**
「客服」提供使用帮助；本群业务问题由对应群管理员处理。
