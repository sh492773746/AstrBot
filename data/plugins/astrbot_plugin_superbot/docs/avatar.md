# 专属头像：使用与维护

> 这是旧版固定合成文档。线上现已切换 `gpt-image-2.5`，以 [AI 头像说明](avatar-ai.md) 为准。
> 下文不再作为线上操作流程；本地合成仅保留兼容与隔离样张用途。

## 用户操作

头像开放后，私聊进入「我的 → 专属头像」，或在已启用的管理群发送 `/avatar`。
入口展示“周”示例；正式效果以本人的预览为准，不使用 AI，不添加水印。

1. Telegram 显示名以“大海传媒”开头，例如“大海传媒·青鱼”。
2. 点击开始，选择自动提取的名字，或自填1～8个汉字、英文字母、数字。
3. 自填时必须回复机器人指定的输入提示，不会采集普通群聊作为名字。
4. 查看预览后确认制作。预览为带“效果预览”标记的缩略图，不扣次数；正式 PNG 无水印，成功保存后占用一次额度。
5. 成品以文件发送，保留原始清晰度。群内制作及领取会在当前群公开。

每个数字 UID 在本机器人内终身两张，群内、私聊共用，改名不重置。
发送失败不再扣次，可从头像首页重新领取原文件；发送结果不明时不会自动重发。
`/cancel` 取消输入；进入其他业务菜单也会退出输入。取消或离开不撤回已经确认的制作。

## 权限与架构

- 模块只接受绑定平台“大海传媒超级机器人”，其余平台不开放。
- 超管在「管理 → 专属头像管理」查看分页记录、预览并确认启停；业务管理员无头像管理权限。
- 首次默认关闭；普通用户只能访问自己的按钮和成品。群入口还要求群管模块和该群都已启用。
- 不增加客服工具、外部 HTTP API、API 密钥、第二个 Telegram polling 或模型生图能力。
- 接入复用现有 Telegram 更新、私聊菜单和插件停止时等待活动请求的生命周期。
- 固定字体为 AR PL UKai，许可在 `assets/avatar/FONT-LICENSE`。不承诺与原示例的书法完全一致。
- 确认绑定用户、聊天、模板内容版本、昵称，十分钟有效，单次使用。
- `avatar_jobs` 为配额及审计事实；`rendering` 和 `ready` 共计最多两张，失败不占额度。
- `avatar_inputs` 持久保存用户、聊天、输入提示消息及有效期，跨用户回复不会生效。
- 图片计算串行、在工作线程执行；忙时拒绝新计算，不创建无限等待队列。退出等待正在计算的线程完成。
- 先写临时文件、同步磁盘并原子更名，再登记成功；文件生成和发送状态分别记录。
- 成品保存在实例数据目录 `avatars/<内部随机编号>.png`，不采用用户输入作为存储路径。

## 预览与上线

隔离样张命令（不接触业务库，不消耗用户次数）：

```bash
python -m data.plugins.astrbot_plugin_superbot.avatar_samples /指定样张目录
```

默认底图为 `assets/avatar/base.png`，入口示例为 `example.png`，字体为 `font.ttc`。
制作只覆盖底图下方固定文字区域，其他像素不变。长名字自动缩小，不移动原图。
修改底图、字体或布局必须重新生成并验收样张；布局代码升级时同步更新模板版本盐值。
新模板上线后旧确认失效，已生成图片仍保留原样；禁止原地覆盖用户成品。

验收后由超管手动开启。头像开关不修改广告、积分、群管授权及其他模块配置。
群内命令列表由现有同步任务更新，私聊菜单仍保持简洁。

## 故障、备份与回滚

- 备份插件（包含字体和底图）、专属配置、一致性 SQLite 快照及整个 `avatars` 目录。
- 磁盘不足导致生成失败时不扣次；若成品已原子落盘但状态写入失败，额度仍保留，重载后从文件恢复。
- 重载将未完成发送标记为待核查，不自动重发；超管记录页可看到该状态。用户明确领取可再次发送缓存文件。
- 对待核查发送，管理员先核对目标会话；不要修改配额或删除任务“重试”。
- 未落盘的中断制作恢复为失败；已保存成品恢复为成功。失败记录、审计和成功图片不会自动清除。
- 数据仍随用户数量增长，需监控数据目录空间。没有自动重置额度、删除审计或压缩数据库操作。
- 回滚先关闭头像模块并等待活动操作结束，再恢复兼容旧代码；不还原整个业务数据库，不删除上线后的额度和成品。
- 旧版本不认识新增表，可以保留新表；重新启用新版仍沿用原额度，不能恢复旧快照绕过限制。
