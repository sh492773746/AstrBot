# 多群主共用机器人

## 当前状态

- 同一个机器人可服务多个经营主体；积分、玩法开关、奖励和广告位按群隔离。
- 新群接入、公众自助开通和独立付款单默认关闭。平台完成权限、模拟支付和真实到账验收后，才可逐步开放。
- 群主不获得平台总控、全局授权、赔率、概率、抽水、平台密钥或服务器权限。

## 群主接入

1. 将机器人加入超级群并授予完成业务所需的 Telegram 权限。
2. 私聊打开「我的群 → 接入群」，取得一次性凭证。
3. 由真实群主在目标群发送 `/bindgroup 凭证`。
4. 回到私聊确认功能。登记后功能仍默认关闭，需在本群逐项启用。

绑定会核对 Telegram 数字用户 ID、群 ID、群主身份和机器人权限。普通管理员不能冒领，已绑定群不能覆盖认领。机器人退群、权限不足或群主变化时暂停新操作，订单和账本保留。

## 管理边界

- **群主可管理**：本群功能启停、签到和聊天奖励、玩法档位与限额、广告位、公开收款地址、订单审核和异常记录。
- **平台控制**：赔率、概率、抽水、全局开关、全局授权、AI／制图预算、全局广告样本和平台密钥。
- 平台开关表示平台允许，本群开关表示本群启用；两者都开启才会受理。
- 地址只保存公开 USDT-TRC20 收款地址，不接收私钥、助记词或交易所登录信息。退款由群主自行执行并提交链上凭证。

## 直付广告

流程：选择本群广告位 → 提交内容 → 群主审核 → 生成付款单 → USDT-TRC20 到账核验 → 发布／置顶。

- 付款单有效期30分钟，金额包含不超过0.000999 USDT 的识别尾数；付款前以订单显示的完整金额为准。
- 收款进入该群主确认的地址，不进入平台广告余额，也不兑换积分。
- 地址、价格、内容、展示时长均保存快照；修改后必须重新审核。
- 少付、多付、迟付、错误网络、重复交易和扫描落后进入核查，不自动发布、不重复收款。
- 发布结果不明时保留订单和付款事实；不要重复转账。退款地址由付款人明确提供，不默认退回原转出地址。

## 付费 AI 与制图

新经营群默认未授权。平台可在本群管理页设置制图或 AI 客服的调用次数预算；预算按群独立、用尽即停，调用失败或结果不明也计入已提交请求。平台密钥不会展示给群主。
