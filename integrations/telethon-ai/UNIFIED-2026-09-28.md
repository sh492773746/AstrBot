## Consolidation

Public controller commands, Managed Bot creation entry/events, native customer
profile/platform enrollment, trial ledger, customer menus, account transport,
persona/model integration and Page management now belong to this one plugin.
The old billing/container controller is not needed for new trial service tenants.
Paid Stars purchase/refund logic was not transplanted into this trial release.

Hardcoded collector config access was removed. The two authorized legacy session
references were imported into a 0600 private registry without copying or connecting
sessions. Fresh installs have an empty registry and empty admin list. An interactive
server-terminal login helper is included; phone/code/2FA never go through a Bot.

## Migration and Recovery

Successful cutover backup:
`/root/Projects/agents/telethon-ai-deployment/unified-20260928T142120`.
The initial attempt used the profile-rename endpoint by mistake, was rejected,
and the legacy Bot/plugin were restored before retrying with the content-update
endpoint. No orders existed at cutover; migration refuses if any order exists.

Rollback must stop only VIP_DHBot, disable the new plugin, restore VIP profile and
required-plugin setting from the private backup, enable the legacy plugin and
restart VIP_DHBot. Do not overwrite live databases wholesale. Once new customers
exist, rollback requires an explicit data migration decision.
