# Tenant Gateway Increment v0.2.0

Implemented and installed as a scoped update, not the complete agreed product.

## Implemented

- Durable trial ledger and audit trail, unique customer Bot/platform mappings.
- Exclusive account assignment and non-overlapping authorized groups.
- Time-limited trials, default disabled; request and group quotas.
- Atomic request reservation and single in-flight request per tenant.
- Tenant-bound conversation sessions; entitlement recheck before LLM and send.
- VIP control private commands with numeric administrator verification.
- Five-minute actor/chat-bound, one-use confirmations for mutations.
- Customer owner-only status/usage/pause menu on already enrolled native Bots.
- Existing controller profile/allowlist untouched; narrow application hook only.
