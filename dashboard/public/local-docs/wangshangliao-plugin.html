开通与使用

  1. 由真实群主或平台群管理员邀请机器人入群，邀请者本人发送开通。
  2. 开通后将机器人设为平台群管理员，才可正常使用本群功能。
  3. 发菜单，逐层回复数字；0返回上一步，「取消」退出并放弃未提交内容。
  4. 群内管理绑定当前群，无须加好友、@机器人或私聊选群。
  5. 私聊发群列表、选择群 1，只能看见和操作本人获授权的群。

群内固定命令、本人菜单会话输入及对应机器人回复统一安排12秒撤回； 原命令仍需平台群管理及撤回权限。普通聊天、私聊、AI闲聊及主动通知不受影响。
