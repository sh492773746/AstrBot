# 旺商聊接入器开发说明

更新：2026-10-20。使用入口见[文档目录](../../../../../docs/wangshangliao.md)，
当前公共合并边界见[架构权限](../../../../../docs/zh/platform/wangshangliao-architecture-permissions.md)。

| 模块 | 责任 |
| --- | --- |
| `adapter.py` / `event.py` | 生命周期、标准事件、可信路由、回复及最终能力入口 |
| `business.py` / `wire.py` | 业务 HTTP、加解密、签名和严格响应验证 |
| `nim.py` | NIM 连接、文本封装、目录及邀请归属 |
| `storage.py` | 密封会话、收发账本、去重、持久化调度与保留 |
| `policy.py` / `moderation.py` | 配置校验、白名单、原生角色、目标保护及回执 |
| `actions.py` | V1 进程内动作契约、账号与业务代次绑定、固定动作分发 |
| `automatic.py` | 自动禁言计次、最多60分钟递进、拒绝旧自动踢出意图与未知结果隔离 |
| `reply_recall.py` | 群内命令及全部对应回复的持久化12秒撤回任务；原命令需可信来源与原生撤回权限 |
| `schedule_store.py` | 每日计划、一次确认、执行与规则审计 |
| `test_window.py` | 接收端单向限时窗口；不授予管理权限 |
| `text.py` | 出站纯文本、有限遮盖与显式推理标签过滤 |
| `identity.py` / `directory.py` | 真实发送者与可信业务UID核验，目录分页完整性及身份冲突拒绝 |
| `group_scope.py` / `runtime_policy.py` | 逐账号逐群运行视图、暂停／离群及规则版本 |
| `invitations.py` | 最新可信邀请、退出及主动加入事件，拒绝旧邀请覆盖新事件 |
| `database.py` | 异步数据库等待、提交前授权及取消边界 |
| `business_http.py` | 有界HTTP交换、锁后授权及明确失败／未知区分 |
| `registration.py` / `dashboard.py` | 后台身份绑定的临时认证、安全码挑战、一次保存能力及旧连接替换 |
| `captcha.py` / `captcha_worker.py` | 有界登录验证与可取消的独立本地求解进程，不是消息服务 |

业务决策属于内置 `wangshangliao_moderation` 插件。不要在传输层解析自然语言，
不要让模型调用任意协议路径，不能复用其他平台入口绕过本平台检查。
群内和私聊共享固定命令；公共AI不调用工具。私聊须显式进入`/chat`；
逐群启用并满足预算、扣费人及权限门禁后，结构化群@、自主接话及冷场
均使用`profiles.resolve("group", account, group)`解析的群聊配置及账号／单群覆盖，不走私聊咨询人格。
群@新键为`platform:GroupMessage:account/group/wsl-ai/account/group/mention/verifiedUid/peer`，
仅从该键读取配置允许的本人有界历史，不跨成员、群、账号或私聊，不迁移或复用旧群客服历史。
自主／冷场仍用原`/wsl-ai/account/group`来源，自主候选缓存不变，`mentions`独立于`autonomous`。
群输出只发送纯文本，不加`【群聊AI】`或`【客服咨询】`前缀，私聊只读AI行为不变。
普通文字仅在本群另行启用自主接话时进入有界上下文；冷场发话是独立开关。
没有逐群启用时，普通文字和@均不启动AI，不能把默认关闭写成永不支持。
旧AI配置器仅保留拒绝兼容壳，不是传输能力或可恢复的管理入口。
测试邀请、移除和角色修改仅由`scripts/`的显式受控工具使用，不向聊天开放。

公共机器人当前集成于共享AstrBot；旧`astrbot-open.service`和公共控制socket不恢复。
`OpenRPC`在进程内分发，名称不代表仍在监听旧socket。独立结账服务仍保留，
通过专用`cashier.sock`桥接受限写入及结构化诊断，不能将两者一并停用或视作同一服务。

## 接口不变量

- 业务 UID、显示账号、NIM ID、业务群 ID、显示群号不可互换；目录失败则失败关闭。
- 支持的入站消息认证并落库后ACK；普通消息和固定命令按同群同发送者排序，
  不保证全群串行，私聊控制消息另有保留槽。重启不重放未知业务动作。
- 最终执行前重查账号、群启用、动作授权、平台角色与目标身份。
- `accepted` 不冒充 `verified`；`unknown` 不用新操作 ID 自动再发。
- 人工禁言不计升级；群主、平台管理员与受管机器人保持保护。
- 测试窗口仅接收端有效，不能绕过回复开关或管理权限。
- 输出过滤不等于输入、历史或日志脱敏；禁止记录协议凭证与完整私密会话。
- `protocol_version`绑定认证会话；3.7.3使用新版签名、请求绑定及消息令牌接口，
  2.8.3桌面会话保留其独立设备头与旧版签名封装，不冒充Android版本；
  无版本的旧会话继续按3.7.1恢复，不静默重写凭证。新登录版本由受保护部署配置选择。
- 安全码只接受已认证后台的临时挑战输入，不保存、不进入模型，不开放设置或重置接口。
  上游成功码是验证回执，JWT轮换可选；还须取得有效NIM令牌才颁发保存能力。
  保存能力不证明WebSocket已在线；验证结果不明不重试。
- 1400至1405按官方整数错误编号区分，不根据可变的错误文案推断账号被封或验证成功。

## V1 动作入口

定时群禁言、名片任务、管理员固定命令、人工同对话确认踢出、旧关键词规则、
内容审核、自动递进禁言、违规撤回及规则警告通过 `adapter.execute_action(request, authorize=check)`
执行，`request` 使用冻结的 `ActionRequest`，由 `ActionRequest.bind` 捕获
实例 ID、当前账号、业务代次和配置修订。`version` 必须为整数 `1`；
未知版本、失效绑定和非法参数在调用原生动作前拒绝，不自动降级到旧入口。

固定动作包含 `mute`、`unmute`、`kick`、`announce`、`mute_all`、
`unmute_all`、`rename`、`cleanup`、`recall` 和 `warning`。接口不授予权限：底层仍检查群授权、
原生角色、目标身份、人工确认以及已有操作账本。名片请求须携带预览
中的原名片和 NIM 身份；清理、违规撤回和警告请求须携带原 NIM 身份。
撤回只接受已落库消息，操作标识必须为 `recall/{account}/{group}/{message}`；
警告校验文本与可选提及前缀，提及范围按 UTF-16 计算，不提供任意协议字段。

两项自动规则动作均需自动处理开关和群能力；普通回复不属于管理动作契约。

`authorize` 是受信业务代码的进程内复核回调，不接收模型或 HTTP 输入。
`schedule/` 请求必须提供回调，且仅支持群禁言开关。其回调在原群锁内
执行，不能在锁外提前占用执行记录。回调等待结束后会再次核对账号代次。
旧自动踢出操作名在 V1 与原生动作入口均拒绝；旧 `auto_kick` 配置不恢复
自动踢出，管理员授权变化后不得继续提交等待中的命令动作。

回执保留原有结果字段，同时固定返回 `version`、`instance`、`account`、
`operation`、`action`、`status`。非法或缺失状态按 `unknown` 处理，不重试。
已完成动作即使随后撤权，回执仍绑定原账号，不丢失上游证据。
发送锁和账本等待后会重验绑定；长回复的所有分段保持原账号及连接，
中途换号不发送剩余段。已发送段保留回执，部分结果未知时不自动补发。

当前契约是同进程 Python 接口，不是 RPC、权限沙箱或独立扩展安装格式。
核心的平台专用注册及配置分支尚未移除，不能宣称完成独立打包。

## 生命周期与证据边界

`settings.py`发布账号绑定的策略快照，`open_service.py`叠加逐群租户状态；
插件停用不退出原生账号，但撤销执行代次、测试窗口及待执行回复。
确认离群后的工作数据清理由持久化代次驱动，按库提交，不是跨库原子事务；
暂停、掉线和目录读取失败不能当作离群，也不能删除返现或未知动作证据。

`friend_auto.py`共享持久化读取间隔至少3秒、自动同意间隔至少30秒，
并分别保留扫描周期、读取退避与未知审批暂停；不能理解成每3秒或30秒必执行一次。
首次私聊、好友欢迎及群开通引导先持久化认领，再发文字和固定图片；
结果不明保留认领，不自动补发。图片使用摘要固定的本地素材和已核验的原生资源ID，
欢迎路径不自动上传，也不把任意URL当作原生图片。好友删除入口不得恢复。

2026-10-20只读核对的运行证据为
`/opt/backups/wsl-group-ai-20261020-format/runtime.json`，预算证据为
`/opt/backups/wsl-ai-enable-20261020T0724Z/enable.json`。
前者仅证明记录时选定群的就绪及一次自主接话`accepted`，后者未测试供应商额度耗尽；
不等于全部群、手机展示或当前持续健康已验收。已知接收和worker限制见
[日志与排障](../../../../../docs/wangshangliao-diagnostics.md)。

## 开发与发布

项目根目录运行 `.venv/bin/python -m pytest -q tests/test_wangshangliao_*.py`。
离线回归使用模拟上游和隔离账本；真实脚本必须另行核对副作用。
接口、权限或持久化变更同时跑插件、后台与前端对应测试。

接入器/框架代码更新需要重启 AstrBot，单独插件热重载不更新核心模块。
重启关闭测试窗口并丢弃内存 AI 配置草案，不清除账本。
发布迁移保留新增审计，详见[维护说明](../../../../../docs/wangshangliao-maintenance.md)。
