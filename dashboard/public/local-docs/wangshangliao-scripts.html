root工具日志保护 / Root CLI Logging

以root运行任何可能导入AstrBot的本地工具时，每条命令显式添加 env ASTRBOT_DISABLE_FILE_LOGGING=1，预览和回归也适用。例如：

env ASTRBOT_DISABLE_FILE_LOGGING=1 .venv/bin/python -m scripts.check_wsl_test_activation_live

该变量仅关闭CLI初始化时的文件接收器，保留AstrBot同一logger及控制台； 不要全局export或加入服务配置，不关闭运行中AstrBot文件日志。 root导入可能创建服务用户不可写的trace文件，2026-10-16已实际导致重启失败； 仅核对后修复受影响文件的属主／0600权限，不递归放宽应用目录，也不删除原日志。 观察前保存NRestarts基线，只检查本次增量；不得清零失败计数伪造通过。
