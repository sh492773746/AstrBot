## 当前群内流程

全部私信功能退役，私信专属业务代码、旧菜单、客服和好友模块已物理删除，
不再提供私信选群、个人知识、私信AI、管理员私信指引、财务聊天及图片收取。
群图文、群AI、活动及原账本保留；历史资料不因删码而清空、重算或公开到群里。
本页同步当前源码入口，不声明本轮已部署、历史数据已清理或手机验收通过；
历史加载和验收记录另见维护记录。

| 场景 | 本群命令或WebUI |
| --- | --- |
| 使用帮助与授权信息 | 已有相应后台权限者使用WebUI帮助和授权管理；群内帮助／身份聊天入口已移除 |

| 拉黑并禁言 | 真正@一人或可信原生回复一人＋`黑名单`，立即按本群时长禁言，不踢人；`黑名单列表`查看 |

| 配图与活动／财务 | 已有相应后台权限者使用群管理→规则、活动与财务；普通群管不获全局后台访问权 |

群内白名单添加不搜索、不选择、不确认；后台名单添加仍按完整当前目录真实名称搜索并预览确认，
不接受UID盲添加。后台黑名单添加只登记，移除只移出、不解禁。
群内拉黑即时禁言与真实重入均使用已确认时长，时长变更不追罚旧名单或重设已有禁言。
`帮助`、`群管帮助`、`help`／`/help`、`我的权限`、`sid`／`/sid`及原前缀写法均不再作为群内命令；
不影响WebUI帮助。`黑名单禁言时长`聊天设置移除不重置已保存时长，
未设置时的默认值仍为41760分钟（29天），后台范围仍为1—41760整分钟。
不能用昵称、UID、手打@、复制引用、多目标代替原生目标；群主、管理员和机器人受保护。
同机器人＋群＋UID新名单互斥，先移除另一名单；历史重叠保留、黑名单优先、分别移除。
未知回执暂停核对、不重试，普通禁言仍最多24小时。

### 名单简写

原命令继续可用，2026-11-02增加以下简写，权限、目标核验、禁言时长和确认流程不变：

| 简写 | 原命令与用法 |
| --- | --- |
| 加黑 | `黑名单`：真正@一名成员或回复其同群原消息，登记并按本群时长禁言 |
| 删黑 | `解除黑名单`／`移除黑名单`：真正@或可信回复一人，移出名单并解禁，分别反馈 |
| 加白 | `白名单`：客户端真正@一名成员后直接加入，不自动解禁 |
| 删白 | `移除白名单 名称／保存旧名／精确UID`：搜索、`选择白名单 序号`、本人`确认白名单 令牌` |

例如`@成员 加黑`、`@成员 删黑`、`@成员 加白`或`删白 名称`。
手打@、昵称和UID不能冒充原生目标；`删白`不增加直接@移除或跳过确认。

## 活动、名片与后台入口

抽奖中奖人数1—100、倒计时1—10080分钟、参与上限及邀请门槛0—10000，
中奖人数不能大于非零参与上限；活动进行中设置冻结。报名只能在活动群进行，
开奖重新核对在群身份，随机结果先落账再统一通知并原生@中奖者；
通知未知不重新抽取。开场、开奖及取消等主动活动通知保留，不属于12秒命令回复清理。
邀请统计先建立当前成员基线，再依据官方业务邀请归属确认后续成员；活动积分不自动付款，
不把原生入群操作者直接当邀请人，不对重复入群重复计奖。排名只统计本地可信文字记录：
北京时间当日、只显示前20名，同成员30秒内最多计一条、同文五分钟内不重复计入，
排除已记录的处罚文字及被撤回消息；不是平台完整发言量。
`排名`、`排行`、`今日排名`、`今日排行`、`排行榜`、`发言排行`、`发言排行榜`
供全部群员查询，不要求查询者具备管理身份；不分页，旧`排名 2`等页码入口也只返回前20名。
逐行格式为`1:昵称（有效发言N条）`，只显示昵称和有效条数，不显示内部UID或传输ID。
按可信成员记录核对昵称，不按昵称猜身份；真实数字昵称保留，无法核实名称时显示“未获取昵称”。
命令及对应回复仍沿用原自动撤回机制；后台统计与导出不因此改成群内公开资料。
内部排序统计仍按UID，自动白名单使用北京时间昨天的榜单：
仅前20名且昨日有效发言超过100条（至少101条）新获资格，不从第21名补位。
每30秒刷新，最近30秒发言待核对；已达标者跨日保留，每次有效文字聊天刷新7天保留期，
连续7天无有效文字聊天退出，总人数可超过20，不额外保存7天正文。
手动名单不变；明确移出不按旧资格加回，须后续日期重新达标。黑名单优先，不授管理权、不自动解禁。

合并模式不显示旧“群聊与运行”“审核配置”页签，逐群广告和刷屏规则在“开通与规则”。
名片修改／清理封禁与注销账号走后台预览任务，不接受AI执行；需要完整成员目录及独立动作授权。
当前手动“名片任务”控件仅挂载于被隐藏的“群聊与运行”，合并模式尚无替代可见入口；
“群授权”仍可设置后缀和自动名片，但不等于提供手动预览、执行、停止任务界面。
名片任务遇受理未核实或未知结果停止继续写入，只能查回执与当前目录核对，不能把未知当失败重发。
处罚警告与原消息撤回分别展示；累计中的`N / 3`是旧界面格式，不是到3次后踢人或自动清零。
