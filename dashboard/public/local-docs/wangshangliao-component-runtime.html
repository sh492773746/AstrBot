组件治理与旺商聊试点

更新：2026-10-21，北京时间。旺商聊插件、管理页和帮助修复已热发布； 通用核心路由及流水线升级尚未加载，/api/v1/plugins/runtime/status仍为404。 组件试点保持关闭，三个原生连接器未重启；不能把插件加载或离线通过当成完整试点验收。

本轮另外通过后台预览确认开通了一个“仅规则”群：只绑定实时核验的原生管理员， 群AI及其工具被后端禁用，不授予套餐或财务角色。规则开通说明见规则与AI分权。 本次回归7055项通过、52项跳过，桌面1440及手机390宽度的线上管理页核验通过。 这是页面及授权状态验收，不是该正式群真实处罚或消息投放验收。

声明与边界

AstrBot 提供版本 1 的 CommandSpec、CapabilitySpec、PageSpec。 公开目录只包含声明，不包含 Python 函数、消息正文、密钥或探针对象。 执行器只调用服务端登记的入口；声明不会授予后台、原生群管、预算或承担人权限。

旺商聊命令能力目录由声明生成，原别名、固定解析器、停用说明和确认令牌保留。 关键词、广告与客服表单复用后端 Pydantic Schema；跨字段、身份、版本、 预览确认与发送检查仍在服务端执行。没有迁移其他插件，也没有引入通用低代码页面、 独立进程或安全沙箱。

执行与恢复

默认每插件最多 8 个在途执行、每能力最多 2 个，繁忙直接拒绝，不排队。 嵌套执行共享已有槽位；尚未结束的取消任务继续持槽。 通用超时为 10 秒，旺商聊固定操作 30 秒，AI 整轮 45 秒；较短的既有期限优先。 超时、撤权或退出使提交和发送租约失效。协作式治理不能终止阻塞的同步代码。

运行故障连续 3 次后熔断 30 秒。业务按账号／群隔离，模型按绑定供应商隔离。 权限、参数、预算、冷却拒绝不计运行故障。探测失败指数退避，最多 300 秒； 仅允许登记为只读、无费用、无写入的探针，最多一个，超时 3 秒。 旺商聊当前未登记自动恢复探针，必须由服务端核对后按状态版本恢复。 模型生成、广告、发消息和财务均不能用作恢复探针。

后台“服务总控 → 组件治理”可查看试点与故障状态，并填写核对记录后恢复。 恢复仅重置运行时熔断，不会清除广告、财务或模型请求的持久化未知状态， 不会重发、补发或自动结算。

服务端专用接口仅接受后台登录身份，不接受委托插件 API Key：

  • GET /api/v1/plugins/runtime/catalog
  • GET /api/v1/plugins/runtime/status
  • POST /api/v1/plugins/runtime/recover

恢复必须提交 capability、精确 scope、version、 operation（probe 或 reset_after_review）及人工核对原因。 旧状态版本、未知作用域、有在途执行或不安全探针均拒绝。操作记录审计。 该接口不接收任意函数、网络地址或配置对象。

规则认领

固定命令、菜单、确认和命中的关键词永久认领消息。 无权限、参数错、冷却、繁忙、熔断或发送失败也不能转入 AI。 仅显式迁移且声明为非关键观察者的处理器，可在未认领时异常后继续； 其他插件保留原 stop_event() 行为。

私聊合并

仅受控窗口内的客服和管理员指引，按首条消息固定等待 2 秒。 按机器人实例、账号、可信发送者、会话代次、角色及配置版本隔离。 最多 12 条、合计 4096 字，超限整批拒绝，不截断。 固定命令、菜单输入、确认、财务及退出立即处理并取消未派发缓冲。 正文只送入只读 AI，不重新解析命令；真正群内 @ 不合并。 热群普通聊天原有 2 秒／12 条／120 秒候选有效期不变。

接收处理器不等待窗口，独立批次任务最多 8 个；正文只留内存。 SQLite 仅记录批次 ID、来源消息 ID 和生命周期。 重启将未派发批次标记丢弃，已派发批次标记结果未知，不重放。 派发与发送前复核身份、角色、配置、会话及窗口。 合并等待计入 45 秒总期限；合并不计费，每次模型请求仍独立计价、扣次和结算。

灰度与回滚

试点默认关闭，仅支持测试群 1459282 与账号 31846829、43506527、23691273，同时要求既有原生受控窗口有效。 开关不创建测试窗口，不增加群管权限，不确认费用或承担人，不扩大目标范围。 原生权限、预算或本人确认不足时，必须报告阻断。

发布先保存配置快照、进程状态和状态差异，再验证三账号及受控私聊。 不改正式群 AI 开关、不改财务账本、不重启连接器。 关闭试点回到兼容路径并撤销试点任务租约；未迁移插件不变。 核心路由或流水线变更需要受控加载时，不应为激活它们擅自重启生产。 内存熔断随生命周期清理，持久化未知业务状态始终保留。
